# Homepage media

The held 1.2.1 website uses four botanical compositions from genuine
Parchmatte 1.2.1 (28) application captures. Two retained terminal examples
keep their original 1.1.0 (26) provenance. Image hashes, sizes and visible
settings are recorded in [homepage-media.json](homepage-media.json).

| Public file | What it shows |
| --- | --- |
| `01-overview.png` | Two Preview windows, Woven and Velvet; Strength 28%, Softness 50%, Page Light off |
| `09-velvet-writing.png` | Botanical document with Velvet; Strength 28%, Softness 50%, Page Light off |
| `02-menu.png` | Separate native menu details and document; Velvet selected among nine textures, Strength 28%, Softness 50%, Page Light off |
| `10-light-shape-controls.png` | Separate native menu details; Tall, Bottom Right, Light Strength 75%, Candlelight, Warm |
| `07-woven-terminal.png` | Retained Woven terminal example |
| `08-denim-terminal.png` | Retained Denim terminal example |

The four new exports use lossless RGB8 PNG. Ancillary density metadata was
removed; image headers and compressed pixel chunks remain byte-identical. Native menu details are presented
as separate panels rather than a continuous fabricated menu. Texture and
controls are not enhanced or invented. All screenshots link to full-size
images; the wide menu details require that view to read fine labels on a
narrow screen.

The terminal examples are lossless crops of a synthetic terminal with the
actual application overlay, at Strength 15%, Softness 35%, Page Light off.
Their original hashes and settings are retained in the JSON receipt.

Publication remains held until 1.2.1 is verified live on the Mac App Store
and the public update has completed its review and approval gates.
