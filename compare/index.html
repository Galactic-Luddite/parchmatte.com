Which one fits?

Night Shift

For warmer colors at night, start with the option already built into your Mac. Night Shift has a warmth slider and a schedule. It doesn’t add texture.

You can keep Night Shift on and use Parchmatte’s grain without Page Light. Night Shift settings.

f.lux

f.lux gives you more control over color temperature through the day and evening. It’s free for Mac and can disable its tint when a selected app is active.

Use it alongside Parchmatte if you want both scheduled color changes and paper texture. f.lux for Mac.

Paperman

Paperman offers nine textures, a Desk Lamp light pool, and a Windows version. It can include or exclude apps; Parchmatte can also cover an individual window.

Parchmatte has eight textures, including Denim, an optional Page Light tint, and source code you can build for free. Paperman on the Mac App Store.
